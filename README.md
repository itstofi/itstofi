## Selected projects

### [PrivateRAG AI](https://github.com/itstofi/PrivateRAG-AI)

A local document assistant built with FastAPI, Streamlit, Ollama, ChromaDB, and SQLite.
It indexes PDF, DOCX, TXT, and Markdown files, keeps workspaces isolated, streams grounded
answers, and provides inspectable source citations without relying on a cloud AI API.

### [Crypto Payment Gateway](https://github.com/itstofi/crypto-payment-gateway)

A full-stack Binance Pay integration demo built with Next.js, Supabase, and Tailwind CSS.
It includes signed payment requests, a local mock checkout, payment-status polling, and an
administration dashboard.

### [EcoWheel Crypto Integration](https://github.com/itstofi/crypto-payment-gateway1)

A NestJS and React payment-flow extension that adds a mock Binance Pay-style checkout to an
existing booking application while preserving its original PayPal workflow.

### [Trade Alerts](https://github.com/itstofi/trade-alerts)

A Python market scanner that evaluates trend, pullback, and rejection conditions before
sending risk-calculated Telegram alerts. It runs on a scheduled GitHub Actions workflow.
